## 状态列说明

| 状态  | 含义                           |
| ----- | ------------------------------ |
| `[ ]` | 未完成，需要生成               |
| `[x]` | 已完成（生成完成后追加时间戳） |
| `[?]` | 待确认（中间状态）             |

**已完成的状态格式**：`[x] YYYY-MM-DD HH:mm:ss`

## XML 标签说明

| 标签                 | 用途                | 模型行为                         |
| -------------------- | ------------------- | -------------------------------- |
| `<project_overview>` | 项目群简介          | 快速理解项目群定位               |
| `<generation_info>`  | 生成快照            | 追溯文档版本                     |
| `<repo_list>`        | 仓库清单和关系图    | 了解仓库间关系                   |
| `<quick_navigation>` | 文件导航 + 生成进度 | 按需跳转到具体文档，支持断点续写 |
