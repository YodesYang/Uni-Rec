## 变更影响速查

> 当你修改某个仓库的代码时，参考此表确认是否需要同步修改其他仓库。

## 仓库间依赖关系

```mermaid
graph LR
    repoA[repo-a] --> repoB[repo-b]
    repoA --> repoC[repo-c]
    repoB --> repoC
```

| 仓库   | 依赖的仓库     | 被依赖的仓库   |
| ------ | -------------- | -------------- |
| repo-a | repo-b, repo-c | -              |
| repo-b | repo-c         | repo-a         |
| repo-c | -              | repo-a, repo-b |

**依赖方向说明**：当 repo-c 变更时，repo-a 和 repo-b 可能都需要适配。

## 接口变更影响

| 变更位置               | 影响的仓库     | 需同步修改的内容      |
| ---------------------- | -------------- | --------------------- |
| repo-b: 某接口签名变更 | repo-a         | 调用处、类型定义      |
| repo-c: 导出函数变更   | repo-a, repo-b | import 语句、调用方式 |

## 变更检查清单

### 修改被依赖仓库时

- [ ] 所有依赖方是否已确认影响？
- [ ] 接口签名变更是否向后兼容？
- [ ] 是否需要协调发布顺序？

### 修改共享内容时

- [ ] 所有使用方是否已测试？
- [ ] 版本号是否已更新？
