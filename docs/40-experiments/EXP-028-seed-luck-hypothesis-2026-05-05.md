### 解读升级

**Row-level valid gap 确实改变了 dev 的性质**：
- 之前所有实验的 dev ≈ 0.868，是**训练期近未来** 的 AUC（dev 位置紧接 train 尾部，时间上高度重叠）
- C6 的 dev ≈ 0.838，是**真正模拟 test 分布**的 AUC（dev 相对 train 有 1 小时 gap，模拟 "远未来" 外推）
- **Dev 从 0.868 降到 0.838 不是"模型变差"，而是"去掉了训练期污染"**

### 推论 A（更新版）：**真实模型能力 ≈ 0.835~0.842**

- C6 告诉我们，去掉训练期污染后 dev ≈ 0.838
- LB SOTA 0.84637，icq-half seed=2 LB 0.841
- 所以真实能力带 ≈ **[0.835, 0.842]**
- **SOTA 0.84637 比真实能力上界高 ~0.004**，这就是"训练期污染 + seed luck"合起来的虚高空间

### 推论 B：**T22/C6 不是失效，是代价过重**

之前 EXP-026 把 T22 判为 Blocked（"funnel 未真正起效"）。**补遗修正**：
- Funnel **机制确实成功了**（dev→LB gap 0.004 对比 0.022）
- **但 C6 LB 0.834 比 SOTA 低 0.012** —— 不是 funnel 的错，而是**训练数据损失 15% 太多**
- Gap 区间可能正好丢掉了最接近 test 的那部分 train 数据

## "SOTA 0.84637 = seed luck" 假说

### 证据

1. **最直接**：换 seed，Dev 只变 0.00004，LB 变 0.005076
2. **历史分布**：所有 non-SOTA config LB 都落在 [0.834, 0.844]，**SOTA 的 0.84637 是孤立的 outlier**
3. **机制**：Evaluation 系统确定性 + Dev AUC 高度饱和 → LB 差异**100% 来自训练轨迹**

### LB 结果的分布（至今所有 evaluation）

```
0.858  ← 社区 SOTA（Seed LB 0.85+）
...
0.850  ← t13tf-full E9 LB（过训练版）
0.846  ← icq-half seed=42 SOTA ⭐（唯一一个接近）
0.845  ← swiglu+time baseline
0.844  ← t13tf-full E4
0.842  ← idmaskc15
0.841  ← C12 icq_seed2, 四合一 holdout 推测
0.840  ← T23 disablefid47
0.839  ← dropout=0.05
0.838  ← icq-full E6 (过训练), t13tf-loss-full E9
0.837  ← C1 disablefid47_29
0.836  ← d_model=128
0.834  ← transformer (错 ckpt)
```

**观察**：
- 绝大多数实验分布在 **[0.836, 0.845]**
- icq-half 的 0.84637 是**离群**的上 outlier（距 C12 seed=2 有 0.005 gap）
- **假设"真实能力带" ≈ [0.839, 0.845]** 是合理的

### 如果假说成立，意味着什么

1. **过去 4 天几乎所有 "LB 负向" 判决需要重新评估**：
   - P1 idmask −0.004 → 可能是 seed 噪声
   - T23 disable47 −0.006 → 可能在 seed 噪声 + 轻度方法学负向交叠
   - 四合一 −0.010, 只有这种量级的才是**真信号方法学负向**

2. **继续追 0.846 基线是错的**：
   - 下一次 icq-half rerun（比如 seed=3）可能 LB 是 0.843
   - 我们真实的 baseline 应该是 `icq-half 多 seed 均值 ≈ 0.843~0.844`

3. **Dev AUC 在 0.868 附近作为决策指标几乎失效**：
   - dev 要达到 0.872+ 才可能 reliably 打破 seed 噪声

## 反面考虑（假说**可能错**的场景）

虽然证据很强，但必须承认以下反面可能：

### 反面 1：icq-half seed=42 确实学到了某个**真实结构**

也许 seed=42 的训练轨迹确实**触达了一个 test-distribution-matched 的 minima**，其他 seed 无法到达。这种情况下 SOTA 不是 luck，而是**稀有 genuine**。但如何确认？需要更多 seed 实验。

### 反面 2：LB 差异主要来自"ckpt 选择"而非 seed

icq-half 的 ckpt 是 `global_step63764.auc=0.868619`（E4 尾部），C12 是 `global_step63764.auc=0.868579`（E4 尾部且 LogLoss 反弹 counter=1）。两者**内部 LogLoss 状态不同**：
- icq-half E4 LogLoss = 0.22336（E3 0.22399 → E4 0.22336，持续下降）
- C12 E4 LogLoss = 0.22355（E3 0.22349 → E4 0.22355，**反弹**）

**所以 C12 的 E4 ckpt 正处于过拟合拐点，而 icq-half 的 E4 ckpt 还没到拐点**。这也可能是 LB 差 0.005 的原因——不是 seed 本身，是**过拟合起点时机不同**。

### 如何区分反面 1/2 和原假说

需要 **≥ 3 个不同 seed 的 icq-half**，且每个都看全部 epoch ckpt 的 LB。但这消耗 quota 巨大（每 seed = 1 training + 多 eval），短期不可行。

**保守解读**：我们已知 LB ±0.003 的波动**部分来自训练轨迹**（seed + ckpt 时机）。

## 结论与后续行动

### 最诚实的结论

1. **SOTA 0.84637 不是完全可复现的上限**，包含 0.002~0.003 的训练轨迹波动
2. **任何"dev 0.868 范围内的 config"的 LB 都会在 [0.840, 0.846] 浮动**，很难用 1~2 次 eval 判真伪
3. **今天所有 "negative LB" 判决需要重新分级**：
   - −0.010+ = 真方法学负向（如四合一 / C1）
   - −0.004~−0.007 = **疑似**方法学负向，也可能 seed 噪声（如 T23 / idmask）
   - −0.002 以内 = **seed 噪声**，无方法学信号

### 立即行动

不消耗更多 quota 做 seed sweep（ROI 低）；**把余下 quota 留给"真正可能破 0.846"的方法学创新**（架构级）。

### 长期行动

1. 未来每次新方法学 ablation 的判决标准从 "LB ≥ 0.846" 改为：
   - "LB ≥ 0.849" = 真信号（明显高于历史 SOTA + seed 噪声上界）
   - "LB ∈ [0.844, 0.849]" = 持平（不可判）
   - "LB < 0.844" = 方法学损害（大概率超 seed 噪声）

2. 方法学级改造优先，砍掉所有小 ablation：
   - DIN target attention（代替 T16 additive）
   - UE 分离 + int pairwise cross（Seed 主楼方案 1）
   - FaFE feature embedding（Seed 主楼方案 2）

3. Test user/item OOV 率 EDA 仍未做，优先级升（~30 分钟工作）
