## Decision Gate

Default evaluation policy:

1. Reserve public quota first for M101-M104 if M101/M103 clean diagnostics pass.
2. Evaluate M105/M106 only if one of these happens:
   - normal dev clearly beats M84 seed42, with no logloss/rebound warning;
   - M101-M104 all fail and a quota would otherwise expire;
   - the aux readout is unexpectedly favorable relative to sibling seed behavior.
3. Do not use these results to reopen the closed time-feature / seqstats / delayed-feedback branches.

## Risk

Cross-seed is high entropy and can produce false hope. This batch is deliberately limited to two jobs so it does not crowd out hypothesis-driven follow-ups after M101-M104 return.
