> **Status**: M123 and M124 completed and evaluated. M123 public **0.851011** is the current LB SOTA; M124 public **0.850718** is near M119.

## Hypothesis

M106 is the current public SOTA at **0.849364**, but its gain is still a
same-family seed/score-max gain rather than a mechanism-level jump. M121 showed
that multi-task click+conversion training is not broken, but it did not beat
M106 under the standard 5% validation split.

The new hedge combines:

- M106 seed5 corrected-T38 backbone.
- Fresher training data by reducing `valid_ratio` from 0.05 to 0.02 or 0.01.
- MTL regularization from M121, using click supervision as an auxiliary head.

This tests whether MTL helps specifically when the model is trained on the
latest public-adjacent supervised rows. It is intentionally narrow: no new time
features, history-CVR, seqstats, AUC loss, or DIN 2.0 variants are reopened.

## Readout Plan

Normal dev AUC is not apples-to-apples with M106 because the validation window
changes. Use these checks:

1. No obvious collapse or logloss rebound.
2. Checkpoint curve should be stable through E4, especially for M123.
3. Aux `m91` is leaky in full-data jobs, so compare only against sibling jobs
   such as M117/M118/M121/M122, not against clean M91.
4. Public eval priority depends on M115-M120 returns. If M117/M118 are weak,
   M123/M124 should usually not consume scarce eval quota unless their training
   curves are unusually strong.

Default: start M123/M124 now as queue hedges, then wait for M115-M118 before
spending public eval quota.
