## Decision Gate

Compare M108 against M107, not against M91:

| Zone | Condition | Interpretation |
|---|---|---|
| green | M108 - M107 >= +0.0004 | M104 mechanism gets second-oracle support |
| yellow | M108 - M107 in [-0.0003, +0.0004) | Keep as information-only; public result decides |
| red | M108 - M107 < -0.0003 | History-CVR likely normal-dev illusion |

This pair was designed to be especially useful after M104 public eval:

- If M104 public improves and M108 also beats M107, continue history-CVR variants.
- If M104 public improves but M108 does not, the gain may be public-window
  specific or stochastic; continue carefully.
- If M104 public misses and M108 fails, close the timestamp-cutoff history-CVR
  branch.
- If M104 public misses but M108 beats M107, treat it as validation-system
  calibration: this window is not a reliable positive oracle for this mechanism.
